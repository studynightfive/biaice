# Provider egress activation boundary

The Compose profile is disabled by default. Enabling `--profile
provider-egress` alone is insufficient: the process exits with code 78 unless
its externally mounted Gate directory contains both:

- `provider-domains.txt`: a non-empty list of exact HTTPS DNS names, sorted and
  canonicalized as one lowercase IDNA hostname plus LF per line; and
- `byok-secret-gate.json`: signed, current `BYOK_SECRET_GATE=PASS` evidence
  whose `catalog_allowlist_sha256` matches the canonical list; and
- `gate-verification.key`: an ACL-protected, at-least-32-byte HMAC verification
  key provisioned by the independent Gate evidence issuer. It must never be
  committed, logged, placed in `.env`, or generated by `scripts/init.ps1`.

`evidence_signature` is `hmac-sha256:<lowercase hex>` over the UTF-8 canonical
JSON object after removing `evidence_signature` (keys sorted, compact JSON).
The gateway uses constant-time verification and exits with code 78 for a
missing, malformed, stale, or invalid signature. A non-empty string alone is
never accepted as proof.

Every tunnel requires an opaque `Proxy-Authorization: Biaice <grant>` value.
The gateway sends that grant only to the internal API; the API must atomically
consume it and confirm the bound host, expiry and single-use state. The proxy
allows CONNECT/443 only, rejects IP literals, rejects any private/reserved DNS
answer, pins the approved public answer for the connection, and revalidates the
Gate on every request. Provider TLS remains end-to-end, so the calling adapter
must perform normal certificate and hostname verification and must send every
redirect through a newly authorized CONNECT.

For a real Gate, mount the evidence directory from a host ACL-protected path
outside this repository. The machine assessment must also include an approved
host-firewall test: Docker network membership and container hardening alone do
not prove that a compromised egress container cannot create an unrelated
socket. Until that evidence and the API authorization endpoint both pass, the
profile must remain off and manual/deterministic flows remain available.
