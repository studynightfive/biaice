# 统一术语表

| 术语 | 固定含义 | 禁止混用 |
|---|---|---|
| Project | 一项采购/投标工作容器，可含多个决策单元 | 不能作为一次正式计算的直接范围 |
| DecisionUnit | 一次正式计算、审批、提交与评估的最小独立单元 | 不等于 Project 或标段组合 |
| Requirement | 从已发布规则形成的可核验要求 | 资格条件不能自动转成评分项 |
| EvidenceMatch | Requirement 与公司证据的双向映射及审核 | 无证据不能自动判满足 |
| ResponseProfile | 已发布、固定的技术/服务/人员响应 | 首期策略搜索不优化其内容 |
| Precheck | 资格与响应预审 | 不检查利润或市场概率 |
| Readiness | 成本、政策、条件是否允许进入策略计算 | 不等于采购有效性 |
| ScenarioAssessment | 独立评估场景上的确定性裁判与聚合 | 压力权重不得混入概率分母 |
| RecommendationEligibility | 是否具备生成正式推荐资格 | 不等于审批决定 |
| RiskAcceptance | 独立授权人对明确风险的版本化接受 | 不由方案制表人自批 |
| ApprovalPackage | 绑定全部输入版本/hash 的不可变审批包 | 不能审批可变前端状态 |
| SubmissionRecord | 外部人工提交的登记与双人核验 | 系统不自动操作采购平台 |
| ProviderConfiguration | 租户对平台目录项的版本化配置元数据 | API Key 明文不进入业务库 |
| ProviderInvocation | 逐次 Gate 后的受控模型调用记录 | 连接测试不等于正式调用 |
| Tombstone | 删除后保留的最小非正文防复活记录 | 不代表仍可业务使用 |
| 正式 | 已满足契约、权限、适用性、冻结与 Gate，可进入受控决策链 | 不等于 Production |
| 探索 | 带水印、不可审批/提交、允许安全试验的结果 | 不得称正式推荐或概率 |

产品表达统一使用“决策辅助、区间、情景、资格、条件、风险接受”；禁止“保证中标、稳妥中标、必然中标”。未建立并验证结果概率模型时不得显示单点中标/胜出概率。
